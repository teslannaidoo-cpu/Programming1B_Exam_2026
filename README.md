# Programming 1B – Java Projects 2026

## Project Overview
This repository contains two Java programming projects developed using Apache NetBeans as part of Programming 1B practice.

## Question 1 – Product Quantity System

This Java application demonstrates:
- Java interfaces and classes
- Arrays and loops
- Methods and calculations
- Displaying results in the console

The program calculates the total quantity of products stored in an array.

**Example Output:**
```text
Total quantity: 30
```

## Question 2 – Mattress Sales Application

This Java Swing application allows users to enter customer details and calculate mattress sales totals.

### Features
- Customer name input
- Mattress product selection
- Product price input
- Calculate Sale button
- VAT calculation at 15%
- Display of sales results

### Available Products
- Cozy Nights Monarch
- Restonic Barbados
- Sealy Phuket

### Example Calculation
For a product price of R1,000:

- Product Price: R1,000.00
- VAT (15%): R150.00
- Total: R1,150.00
